# ✨ Stellar Truths — Brutally Honest Horoscope

> **VishwaNova 2026 · National Level Weboreel AI Hackathon**

Your horoscope has been lying to you. "Stellar Truths" replaces toxic positivity with brutal cosmic clarity. Select your sign and current burden to receive a personalized, savage reading of what the stars actually think of you.

## ✨ Features

- 🌌 **Deep Space Canvas**: The background utilizes an HTML5 Canvas to render hundreds of twinkling stars procedurally. Combined with a 60-second rotating CSS zodiac wheel (drawn using semantic SVG masks) and occasional shooting stars, the aesthetic feels genuinely cosmic.
- 🔮 **Interactive Selection Engine**: Users select from the 12 Zodiac signs arranged in a perfect geometric circle via CSS `calc() / Math.sin()`. They then choose from 6 glassmorphism "Problem Chips" (Money, Love, Career, Existential Dread, etc.).
- ✍️ **Typewriter Unfurl Reveal**: The result triggers an SVG constellation `stroke-dashoffset` animation alongside a parchment scroll reveal. The brutal reading types out procedurally synchronized to Web Audio API mechanical typing tones.
- 💔 **Compatibility Risk Calculator**: Select another sign to dynamically (and often hilariously) calculate your "compatibility risk" ending with a snarky celestial commentary in a speech bubble.
- 📱 **Community Truths Gallery**: A grid of exactly 12 mini-cards displaying a savage one-liner for every single zodiac sign today. It checks `localStorage` to permanently highlight *your* sign in gold whenever you visit the gallery.

## 🛠️ Tech Stack

- **HTML5** — Multi-screen SPA structure, `<canvas>`, inline `<svg>` masks.
- **Vanilla CSS3** — Fluid geometric circle layouts, animated dashes, glassmorphism filters, staggered opacity loading.
- **Vanilla JavaScript** — Real-time typing engine, DOM injection, trigonometry for circle placement, state management.
- **Web Audio API** — Procedural mystical chimes (built with chained minor/major sine waves) and organic square-wave typewriter pings.

## 📸 Try It Out

Simply double-click the `index.html` file to open it in any modern browser. No servers, build steps, or dependencies required.
